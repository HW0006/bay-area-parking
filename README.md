# Bay Area Parking — 灣區停車指南

A bilingual (English + Traditional Chinese) parking guide for 9 Bay Area cities: Campbell, San Jose, Palo Alto, Saratoga, Los Gatos, Fremont, Cupertino, Menlo Park, and Atherton. 21 lots with cost, time limits, hours, typical availability, and Waze navigation links, plus one-tap crowd reports (Lots / Few / Full, 30-minute expiry).

中英雙語的灣區停車指南，涵蓋 9 個城市、21 個停車場：Campbell、San Jose、Palo Alto、Saratoga、Los Gatos、Fremont、Cupertino、Menlo Park 和 Atherton。每個停車場都有費用、時間限制、營業時間和 Waze 導航連結，還有一鍵回報空位（很多／剩不多／滿了，30 分鐘後過期）。

Live site / 正式網站：https://hw0006.github.io/bay-area-parking/

San Jose links out to ParkSJ (https://parksj.org/) for real live garage counts. No live counts are invented anywhere else.

San Jose 可連到 ParkSJ 看真正的即時車位數，其他地方沒有捏造即時數字。

Note: in this first version, crowd reports save on your device only (localStorage), so other people's reports don't show up yet.

注意：第一版的回報只存在你自己的裝置上（localStorage），還看不到別人的回報。

Built with Muse, November 2026. Free, single-file site — just open `index.html`.
